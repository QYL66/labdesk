# LabDesk 固定资料问答评测

评测使用三份实验室演示资料和本目录的四份补充文档。补充文档是隔离评测素材，其中的冲突记录不属于正常实验室资料。

1. 在独立的 LabDesk 测试环境中，将 [演示资料](../../resources/labdesk-demo) 和 [补充资料](fixtures) 上传到同一知识库。等待七份资料都分块成功。评测前确认该环境只有这套评测资料参与召回。
2. 启动 LabDesk，通过管理员账号调用本机评测脚本。脚本会在本机读取密码。

```powershell
python docs/evaluation/run.py
```

3. 在 `local/logs/labdesk-evaluation.jsonl` 核对每条问题的期望、独立检索调用返回的片段、流式答案、引用与耗时。检索接口记录的片段来自独立请求，同次真实问答的引用也单独保留。
4. 用 [问题集](questions.json) 中的预期和出处对照结果。脚本标记缺少的答案标记和引用。无答案时是否编造、遇到冲突时是否正确说明分歧，按原文人工判定。

| 场景 | 核对重点 |
| --- | --- |
| 有答案 | 结论与规程中的唯一规则一致。 |
| 无答案 | 明确资料未记录，不生成虚构序列号。 |
| 资料冲突 | 同时列出两项周期和各自出处。 |
| 同名设备 | 房间、编号与各自归位动作正确配对。 |
| 来源核对 | 最后时段的起止时间与预约规则一致。 |

评测输出留在本机，包含检索到的原文片段。

2026-11-15 在 LabDesk 本机环境实跑以上五类问题，逐条核对了答案和来源。无答案项明确说明资料未记录序列号。冲突项列出两份文档的不同周期；同名设备项正确区分了房间和设备编号。这次记录用于验证这套样例，模型和网络变化会影响重跑结果。
